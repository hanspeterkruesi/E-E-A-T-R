## 3. How to Submit Contributions

To maintain data hygiene and code compliance, please follow this pull request pipeline:

1. **Fork the Repository:** Create your own branch based on the `main` branch.
2. **Implement & Test:** Ensure your templates or plugin code validate seamlessly against the official W3C Semantic Web and Schema.org validators.
3. **Document Your Stack:** Provide clear configuration details (e.g., server requirements, caching trade-offs).
4. **Submit a Pull Request (PR):** Clearly label your PR according to its ecosystem target (e.g., `feat: wordpress-jsonld-template`).
